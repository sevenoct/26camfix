# CamFull (pendamping 26Cam Legacy, iPhone 7 / iOS 15)
Gantikan CamFix: hapus CamFix, install CamFull.
Build: taruh isi folder ini di root repo GitHub -> Actions -> artifact CamFull-deb.
Setelah install buka Kamera: harus muncul teks hijau kecil "CamFull 0.2 | mode:..." di kiri atas.
Kalau teks tidak muncul = tweak tidak aktif di Kamera (kirim screenshot).
Pengaturan: Settings -> CamFull.
